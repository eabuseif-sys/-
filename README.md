# Rabyana Al-Zahira Website

صفحة واحدة (ملف index.html) بدون أي مكتبات. عربي أساسي + إنجليزي.
Single-page static site (one `index.html`), Arabic default with an English toggle.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) وارفع `index.html` و `README.md`.
2. Settings > Pages > Source: Deploy from a branch > main / root.
3. سيظهر الموقع على `https://USERNAME.github.io/REPO/`.
